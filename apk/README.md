# Dot Crosshair - APK Compilado

Este diretório contém o arquivo APK pré-compilado e pronto para instalação em dispositivos Android (versão 8.0 até Android 14+).

## Arquivos:
- `DotCrosshair.apk` (9.7 MB) - Versão pronta para instalação direta.
- `DotCrosshair-v1.0.apk` (9.7 MB) - Release v1.0.

## Como Baixar e Instalar no seu Android:

1. Acesse o seu repositório no **GitHub** pelo celular (ou baixe no PC e transfira via USB/WhatsApp/Drive).
2. Clique no arquivo `DotCrosshair.apk` e selecione **Download** (ou **View raw**).
3. Abra o arquivo `.apk` baixado no seu celular.
4. Caso o Android solicite, ative a opção **"Permitir desta fonte"** para instalar aplicativos fora da Google Play.
5. Conclua a instalação e abra o **Dot Crosshair**.
6. Ao abrir o aplicativo pela primeira vez, toque em **"Conceder Permissão"** para autorizar a exibição sobre outros aplicativos e jogos.
7. Ative a mira e personalize o tamanho e cor como preferir!
